Guarda tu clave de recuperación

Es la única forma de recuperar el acceso si olvidas tu contraseña maestra. Guárdala en un lugar seguro — no la compartas ni la subas a ningún sitio. Quien la tenga, junto con acceso a este tablero, podría leer las contraseñas guardadas.

Las contraseñas y notas se cifran en tu navegador (AES-256) antes de guardarse. Sin tu contraseña maestra o tu clave de recuperación, no se pueden leer.

Creados y mantenidos por Workhub

Exporta una copia de seguridad completa (tareas con sus notas, reuniones, contactos, clientes y contraseñas cifradas) en un archivo .json, o restaura una desde un archivo. Importar añade a lo que ya tienes — no borra ni reemplaza nada.

El archivo incluye las contraseñas ya cifradas, nunca en texto plano — pero sigue siendo un archivo sensible: guárdalo con el mismo cuidado que la clave de recuperación. Las contraseñas solo se importan si este tablero todavía no tiene una contraseña maestra propia configurada; si ya la tiene, se omiten para no dejarlas ilegibles. Las imágenes de las notas solo se conservan al restaurar en este mismo tablero.

    Las tareas cuya etapa ya no exista pasarán a la primera columna. No se pierde ninguna.

    Se borrará todo lo que hay dentro: tareas y notas, reuniones, contactos, contraseñas y clientes de este proyecto. No se puede deshacer; si quieres conservarlo, exporta antes una copia de seguridad desde el proyecto.

    Compartir proyecto

    • Se crea un proyecto de equipo con una copia de sus tareas (con notas e imágenes), clientes, contactos y reuniones.
    • Las contraseñas guardadas no se copian: todavía no se pueden compartir con seguridad.
    • El proyecto original no cambia; si ya no lo quieres, puedes eliminarlo después.
    • Está enlazado con GitHub: el enlace pasa al equipo y el original deja de sincronizar. Cada miembro conecta su propia cuenta de GitHub, porque el acceso no se comparte.
